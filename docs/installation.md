# Installation

1. Install via **HACS** (custom repository → this GitHub URL → type *Integration*).
2. Restart Home Assistant.
3. **Settings → Devices & services → Add integration** → **Enterprise Car Club**.
4. Sign in with your Enterprise Car Club member ID and password (the same
   details as the phone app). Pick the UK programme when asked.
5. Optional: **Configure** the entry to set the search location (defaults to
   your Home location), the availability window, and favorite vehicles.

For pre-release dogfooding see [pre-releases.md](pre-releases.md).
